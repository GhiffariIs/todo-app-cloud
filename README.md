# Todo App - React + Node.js + SQLite

Aplikasi Todo List sederhana dengan fitur Create, Read, Update, dan Delete (CRUD).

## Teknologi yang Digunakan

- **Frontend**: React
- **Backend**: Node.js + Express
- **Database**: SQLite

## Cara Menjalankan Aplikasi

### 1. Install Dependencies

#### Backend
```powershell
cd backend
npm instal

#### Frontend
```powershell
cd frontend
npm install
